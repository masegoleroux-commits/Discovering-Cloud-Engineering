# 0002 Two-layer origin protection

Status: Accepted

## Context
If the ALB is reachable directly, attackers can bypass CloudFront and WAF.

## Decision
Layer 1: the ALB security group allows only the AWS-managed CloudFront origin-facing prefix list. Layer 2: CloudFront adds a random `X-Origin-Verify` header, and the ALB forwards only requests that carry it; everything else gets a 403.

## Alternatives rejected
- **Prefix list only:** blocks the internet, but any CloudFront distribution (including an attacker's) could still reach the ALB.
- **Header only:** the ALB would still accept connections from anywhere, leaving it exposed to floods.

## Consequences
Both have to be bypassed to reach the servers. The secret is generated by Terraform and stored in state, so the state file must be treated as sensitive. Rotating it means a new password and one apply.
