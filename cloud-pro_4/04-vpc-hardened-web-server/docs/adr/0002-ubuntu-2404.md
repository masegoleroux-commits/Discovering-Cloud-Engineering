# 0002 Ubuntu 24.04 LTS

Status: Accepted

## Context
The instance needs a supported Linux distribution with the SSM agent available.

## Decision
Use Ubuntu Server 24.04 LTS, found through Canonical's public SSM parameter so the AMI ID is never hard-coded.

## Alternatives rejected
- **Amazon Linux 2:** reaching end of standard support. Check the current AWS announcement and cite it here.
- **Amazon Linux 2023:** a good choice too; Ubuntu was chosen because its `apt` workflow is common in job descriptions.

## Consequences
Long-term support until 2029. The SSM agent comes pre-installed as a snap package.
